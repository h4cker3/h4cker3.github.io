# Одновременный доступ к Telegram и Supabase

Для подключения, где Telegram доступен через VPN, а Supabase — напрямую, в INCY или Happ нужны правила по сайтам внутри активного профиля маршрутизации:

| Поле | Добавить |
| --- | --- |
| DirectSites / Напрямую | `sdcibpxxwpqqkglrfezu.supabase.co` |
| ProxySites / Через прокси | `oauth.telegram.org` |

Добавлять только доменные имена, без `https://` и путей. Сохранить существующие правила профиля. Ритм должен быть включён в приложения, обслуживаемые VPN: исключение всего приложения отключает применение правил к его запросам. Telegram оставить через VPN.

Сохранить профиль, отключить и снова подключить VPN, затем закрыть и открыть Ритм и повторить вход. Проверить оба этапа: переход в Telegram и загрузку задач после подтверждения. Настройки Supabase и BotFather менять не нужно.

APK 0.1.4 показывает «Входим…» во время запроса и блокирует повторное нажатие. Повторный вызов нативного входа возвращает текущую операцию без ошибки. Таймаут показывает подсказку по домену Telegram. Сам APK не перенастраивает VPN; доступ к обоим сервисам зависит от правил и работоспособности выбранного VPN-сервера. Настройка доменов также подходит для APK 0.1.3.

Если провайдер поставляет заблокированную JSON-подписку Happ, её маршрутизация может быть недоступна для редактирования: понадобится изменение профиля у провайдера либо редактируемая подписка.
